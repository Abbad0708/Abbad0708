## 👋 About me

I'm a Computer Science student who likes to turn curiosity about new technology into things people can actually run. Right now that means **tooling around large language models**: I'd rather build the instrument that lets you measure a dozen models at once than argue about which one is "best".

- 🔭 **Currently building:** [Muster](https://github.com/Abbad0708/Muster), a self-hosted app that sends one prompt to up to 12 LLMs and lays the answers out side by side
- 🌱 **Currently learning:** systems design for local-first apps, provider APIs and SDKs, and writing tests that catch real bugs
- 💬 **Ask me about:** comparing LLM providers, Node.js without a build step, keeping data on your own machine
- ⚡ **Working principle:** small surface area, no unnecessary dependencies, everything runnable with `npm start`

    <td width="60%" valign="top">
      <h3><a href="https://github.com/Abbad0708/Muster">Muster</a></h3>
      <p><em>To muster: to gather and assemble.</em></p>
      <p>One prompt, up to twelve models, answers side by side. Muster is a local, single-user web app for comparing LLMs honestly: every model only ever sees its <strong>own</strong> conversation history, so follow-ups stay a fair test.</p>
      <ul>
        <li>Parallel streaming into per-model cards, with retry for a single failed model</li>
        <li>Rendered Markdown, Perplexity citations as links, truncation flags</li>
        <li>Full-text search across every prompt and answer</li>
        <li>Chats stored in a local SQLite file; no sign-in, no telemetry</li>
        <li>Plain HTML/JS frontend, <strong>no build step</strong>; custom DOM-based Markdown renderer (no <code>innerHTML</code>)</li>
